# 03 阅读器

> 本节目标:**掌握阅读器的目录树、正文渲染与上下篇导航**,并理解 md 课件与书籍类两种形态的区别。

---

## 3.1 三栏布局

```
┌──────────┬────────────────────┬───────────┐
│ 左:目录树 │      中:正文        │ 右:AI 面板 │
│          │  (排印渲染)         │ (问 AI 开) │
└──────────┴────────────────────┴───────────┘
```

- **左栏**:章可折叠(▾/▸);点击章标题进入章 README;小节直接进入正文。目录树就绪时自动展开含当前节的那一章。
- **中栏**:正文渲染区;顶部 header 有全部操作按钮。
- **右栏**:点「问 AI」展开(仅 md 课件)。

## 3.2 目录树是怎么来的

打开课件时,系统优先读根 `INDEX.md` 的目录表(`| 01 | [标题](路径) |` 格式);若是目录章(链接指向 README),再解析 README 里的目录表得到小节。没有 INDEX.md 的课件会按文件名数字前缀(如 `01_xxx.md`)回退组织。

AI 著书生成的课件、导入的课件、EPUB/PDF 书籍都遵循同一套解析规则——目录链接在应用内跳转,不刷新页面。

## 3.3 header 上的按钮

| 按钮 | 说明 |
|------|------|
| 问 AI | 展开右侧面板(仅 md 课件) |
| 续写 | 仅 AI 著书来源:沿课时规划补齐缺失课时 |
| 整书改写 | 按「改写要求」重写全书(内置课件先自动另存副本) |
| 导出 zip | 打包当前课件全部文件下载 |
| 设置 | AI 端点配置 |
| ← 上一篇 / 下一篇 → | 按目录扁平序列前后移动 |

## 3.4 md 课件 vs 书籍

| | md 课件 | EPUB / PDF 书籍 |
|---|---------|-----------------|
| 渲染 | Markdown 排印(代码高亮 + ASCII 图等宽) | EPUB 章节净化 HTML / PDF 逐页等宽文本 |
| 划词问 AI | ✓ | ✗(纯阅读) |
| 改写 / 续写 / 整书改写 | ✓ | ✗ |
| 导出 zip | ✓ | ✓ |
