# 01 开始之前

> 本节目标:**弄清墨痕是什么、数据存在哪里、怎么配置 AI**,然后放心开始用。

---

## 1.1 墨痕是什么

墨痕是一个**纯静态**的 AI 陪学站:没有服务器、没有账号、没有数据库。

- **书架**:陈列你导入的课件与书籍,按自建分类归档。
- **阅读器**:左目录、中正文、右 AI 面板;md 相对链接在应用内跳转。
- **问 AI**:划词发问或自由提问,AI 会翻阅、检索当前课件再作答。
- **AI 著书**:给一个主题,先出课时规划,确认后逐课时流式成书。
- **导入导出**:zip / tar.gz / rar / 文件夹,以及 PDF / EPUB 书籍。

## 1.2 数据存在哪里

| 内容 | 存放位置 | 会跟着浏览器走吗 |
|------|----------|------------------|
| 导入的课件 / 书籍 | 浏览器 IndexedDB(`moxue` 库) | 不会,仅本机 |
| 分类与归属 | localStorage(`moxue-categories`) | 不会,仅本机 |
| AI 端点与密钥 | localStorage(`moxue-settings`) | 不会,仅本机 |
| 风格 skill | localStorage(`moxue-skills`) | 不会,仅本机 |
| 本指南 | 随站点静态资源 | 随部署 |

**密钥永不进导出文件**——导出课件 zip 时只包含课件内容本身。

## 1.3 配置 AI(第一次使用必读)

1. 点书架右上角「设 置」。
2. 选一个服务商预设(DeepSeek / OpenAI / 通义 / 智谱 / Claude),或选「自定义端点」手填请求地址。
3. 填入你的 API Key(可在「获取密钥」直达控制台)。
4. 模型可手填,也可点「拉取模型列表」从端点拉取。
5. 点「测试连通」,显示「连通成功」即可。

浏览器直连要求端点允许跨域(CORS);若提示网络失败,大概率是端点不支持浏览器直连,可自建代理后把代理地址填入请求地址。

## 1.4 三种内容来源

| 来源 | 标签 | 怎么来 | 可否编辑 |
|------|------|--------|----------|
| 内置 | 内置 | 随站点携带(如本指南) | 只读,AI 改写前自动另存副本 |
| 导入 | 导入 | 导入对话框 / 拖拽 | 可直接编辑 |
| AI 著书 | AI 著书 | 生成流水线 | 可直接编辑、续写 |
