# 04 问 AI

> 本节目标:**用三个入口把 AI 变成陪读者**——划词发问、自由提问、改写本节;并看懂「工作流程」时间线。

---

## 4.1 划词发问

在正文里**划选一段内容**,选区右下角会浮出一枚朱红「问」印,点击即把「选区 + 所在节标题 + 前后文」打包发给 AI:

```
… 段落文字 【用户划选】进程控制块 【后文】…
      ┌────┐
      │ 问 │  ← 点击发问
      └────┘
```

每次划词都会**开一轮新会话**(旧对话清空,避免上下文串味)。

## 4.2 自由提问 + Agent 检索

在面板底部输入框直接提问。问 AI 不是普通聊天——它是**带工具的 agent**:

1. AI 可调用三只只读工具:`list_course_files`(浏览目录)、`read_course_file`(读文件)、`search_course`(全文检索)。
2. 需要跨节/跨文件信息时,它会先检索再精读,一轮最多 8 次工具调用。
3. 全部过程在「**工 作 流 程**」时间线里展示:每一步 ◐ 进行中 / ✓ 完成 / ✕ 失败,点「详情」可看工具原始输出。

首条自由提问可勾选「附上本节全文」,让 AI 不查直接答;后续追问由 agent 按需自查。

## 4.3 改写本节

切到「改写本节」模式,输入修改要求(如「精简本节」「补一个例子」):

- AI 输出改写后的完整正文(流式)。
- **满意再点「应用到本节」**——不满意可继续提要求再改。
- 应用后正文立即刷新;内置课件会自动另存为副本再应用。

## 4.4 追问与历史

同一轮会话里的追问会带上前几轮问答(短文本形式),不用重复背景。
