# 05 AI 著书

> 本节目标:**走通 AI 著书全流程**——意向 → 课时规划(可商量)→ 逐课时生成 → 续写与整书改写;并理解风格 skill 的作用。

---

## 5.1 课时制流水线

AI 著书采用**课时制**:一部书 = `INDEX.md` 目录 + `lesson01.md lesson02.md …` 各课时文件。

```
【意向】主题 + 需求粘贴
   ↓
【规划】8~16 课时,每课时 3~6 条要点   ← 可编辑/增删/调序
   ↓ (确认)
【生成】逐课时流式出稿(单课时失败自动重试一次)
   ↓
【入库】书成,回书架开读
```

「需求」直接粘贴你已有的东西:课程大纲、课时数要求、目标读者、风格偏好……AI 会尽量照办。

## 5.2 和 AI 商量规划

规划出来后**不必一次定稿**:在「和 AI 商量这版规划」框里说想怎么改(「压缩到 10 讲」「第 4 讲拆成两讲」「加两节 X 砍掉历史」),AI 输出修改后的完整规划。

- 标题未变的课时**沿用其文件与状态**(续写时已生成的内容不会因改规划而重写)。
- 修改后可一键**撤销**,回到上一版。

## 5.3 风格 skill

**风格 skill** = 一份可复用的「写作风格规范 + 样例节」,生成时注入 prompt,让产出延续同样的文风与骨架。

| skill | 说明 |
|-------|------|
| 墨痕课件风(默认) | 随应用内置:类比 → 定义 → ASCII 碑刻图 → 对比表 → 自我检测 → 尾导航 |
| 你提炼的 skill | 在著书向导里点「提炼新 skill…」,选一门自己的课件,AI 通读后总结成规范(可编辑后保存) |
| 极简骨架 | 不注入风格规范,只按最基本结构写 |

## 5.4 续写 / 整书改写 / 生成中断

- **续写**(AI 著书来源的课件):Reader 里点「续写」,恢复当初的课时规划,已有正文默认勾「跳过」,只补缺失课时;勾掉的「跳过」会重写。
- **整书改写**:对任何 md 课件,按一段「整体改写要求」(如「面向零基础,多打比方」)重写全书;可勾「跳过」保留个别课时。
- **生成中断**:点「停止并保留已完成课时」,已完成部分照常入库,不会前功尽弃;失败课时可事后「重写失败课时」。
