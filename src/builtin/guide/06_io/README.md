# 06 导入与导出

> 本节目标:**用导入对话框把课件 / 书籍请进书架**,再用「导出 zip」把内容带走;并理解入库时的清洗规则。

---

## 6.1 课件导入

支持三种形态,拖入「拖入文件到此」区即可(也可点「选择文件 / 选择文件夹」):

| 形态 | 支持格式 |
|------|----------|
| 压缩包 | zip / tar.gz / rar(RAR 组件首次使用时动态加载) |
| 文件夹 | 整门课的文件夹(拖拽或目录选择,保留子目录结构) |
| 多选文件 | 一次拖多个文件 |

**入库清洗规则**:

- 只收文本类扩展名(md / txt / 代码 / 配置等),单个文件 ≤ 2MB。
- 自动剔除垃圾:`.git`、`.claude`、`target`、`__pycache__`、`.DS_Store`、`._*` 等。
- 若所有文件共享同一个无扩展名的「文件夹根」,自动剥掉(压缩整门课的包常见此形态)。
- 全部按 UTF-8 文本解码存入 IndexedDB。

导入前可在顶部选「归入分类」,也可稍后在书架拖拽调整。

## 6.2 书籍导入:PDF / EPUB

拖入单个 `.pdf` 或 `.epub` 文件自动走书籍分流:

- **EPUB**:解包 → 按 spine 顺序抽各章正文(净化为纯阅读标签),入库为 `epub/01.html …`。
- **PDF**:逐页抽取文本(不含图片),入库为 `pdf/p01.txt …`。

两者都会由代码生成 `INDEX.md` 目录表(章 / 页),入库后**纯阅读**:不做划词、问 AI、改写。

## 6.3 导出 zip

阅读器 header 点「导出 zip」:当前课件全部文件打包为 `{标题}.zip` 下载。

- 导出**只含课件内容**,不含你的 AI 密钥与分类数据。
- 个别文件缺失时会在提示里说明跳过数量。
- 这是把内容换机/换浏览器带走的唯一通道(内容都在浏览器本地)。

## 6.4 存储限额

入库前有配额预检:浏览器存储用量超过约 95% 时会拒绝入库并提示需要/可用空间。书籍(尤其 PDF)可能占用较大,建议定期清理不要的内容。
