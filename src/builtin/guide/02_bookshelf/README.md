# 02 书架与分类

> 本节目标:**学会用书架陈列与归档内容**——新建分类、拖拽归档、删除与移出。

---

## 2.1 书架的布局

书架按「分类」分组陈列:每个分类一个区块,标题右侧显示数量;未归入任何分类的内容落在最下方的「未分类」组(非空才显示)。

每张卡片上有:

- **印章**:md 课件为朱红「课」印(取标题首字);书籍为墨色「书」印。
- **删除按钮**(右上,悬停出现):内置课件没有删除——它们随站点携带。
- **移出按钮**(左上,悬停出现):仅已归类的卡片有,一键回到未分类。
- **来源标签**:「内置 / 导入 / AI 著书」。

## 2.2 分类完全由你自建

没有预置分类。点书架底部「＋ 新建分类」,输入名称(如「学习 / 课本 / 小说」),Enter 确认。

- 空分类也会展示(方便先建组再拖入)。
- 删除分类只删分组,其中内容自动回到「未分类」,不会丢失。

## 2.3 拖拽归档

把卡片**拖到**目标分类的区块上(区块会出现朱红描边),松手即完成归档:

```
┌─ 学习 ──────────────┐
│  ┌────────┐  ┌────┐ │
│  │ 卡片 A │  │ B  │ │   ← 拖到这里
│  └────────┘  └────┘ │
└─────────────────────┘
```

拖动时出现的「封面式」拖影(印章 + 书名)替代了浏览器默认的 URL 拖影。

## 2.4 书架的三个入口

| 入口 | 干什么 |
|------|--------|
| AI 著书 | 打开生成向导(见第 05 节) |
| 导入 | 打开导入对话框(见第 06 节) |
| 设 置 | AI 端点与密钥(见 1.3) |
